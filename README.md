# Jogo do Número Secreto

Este é um projeto desenvolvido durante o meu aprendizado inicial em programação. O objetivo é criar um jogo interativo onde o usuário deve adivinhar um número secreto gerado aleatoriamente pelo sistema.

## 🚀 Tecnologias Utilizadas

* **JavaScript**: Lógica do jogo e manipulação do DOM.
* **HTML5**: Estrutura da página.
* **CSS3**: Estilização visual.
* **ResponsiveVoice API**: Utilizada para adicionar funcionalidade de voz ao jogo.

## 🎮 Como Jogar

1. O computador gera um número secreto entre 1 e 100.
2. Você deve digitar um palpite no campo indicado.
3. O jogo informará se o número secreto é **maior** ou **menor** que o seu palpite.
4. Continue tentando até acertar!
