## 📝 Descrição do Projeto
O "Jogo do Número Secreto" é uma aplicação web interativa onde o objetivo é adivinhar um número gerado aleatoriamente pelo sistema. Este projeto é uma excelente prática para consolidar conhecimentos fundamentais de lógica de programação, manipulação de DOM e integração de APIs de voz.

## 🚀 Funcionalidades e Demonstração da Aplicação
* **Sorteio de números:** Gera números aleatórios entre 1 e 100.
* **Validação de palpites:** Feedback visual e sonoro indicando se o número é maior ou menor.
* **Dicas por voz:** Utiliza a API *ResponsiveVoice* para narrar o feedback do jogo.
* **Reinicialização:** Possibilidade de reiniciar o jogo após acertar.
